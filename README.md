# 薛甄珠：幽灵权限

《我的前半生》经典冲突场面的赛博朋克改编企划。故事保留薛甄珠为女儿出头、当面质问凌玲的情感关系与戏剧力量，将婚姻、财产和背叛重新解释为未来城市里的身份系统与权限侵占。

> 当前阶段只锁定开场世界观与人物设定，具体分场和生成提示词后续逐幕开发。

## 核心概念

公元 2097 年，城市公共服务早已被巨型企业接管。婚姻不再只是一纸证书，而是一组绑定住房、医疗、信用、子女监护权和记忆备份的“家庭联合账户”。

配偶可以把部分家庭资源授权给第三人。为了维持体面，有些人利用企业内部权限隐藏这些记录。系统将这种未经家庭成员同意、没有公开身份却持续占用家庭资源的人，标记为：

**幽灵关系持有人。**

陈俊生偷偷将凌玲加入自己的家庭账户，为她开放住房额度、医疗优先级和私密通信权限。薛甄珠发现女儿的家庭资源正在被一个没有姓名的账户持续抽走，于是带着一枚无法被企业远程删除的实体存储芯片，亲自来到陈俊生所在的巨型企业。

这仍然是一个母亲替女儿讨回尊严的故事。霓虹、义体和算法只是这个世界掩饰人性的工具。

## 开场序幕

### 画面

全黑画面。字幕使用略带磨损感的冷白色窄体字，居中出现。文字之间留出较长停顿，背景偶尔掠过微弱的蓝色扫描线。不要快速滚动，不出现复杂界面和解释性图标。

### 字幕正文

> **公元 2097 年。**  
> 巨型企业接管了城市的身份、住房与婚姻系统。  
>  
> 每个家庭共享同一个账户。  
> 信用、医疗、住所与记忆，都由权限决定。  
>  
> 有人忠于家庭。  
> 有人修改权限。  
>  
> 未经登记，却持续占用家庭资源的人，  
> 被称为——**幽灵关系持有人。**

字幕熄灭。黑暗中先响起一声清晰的高跟鞋落地声。

画面切入雨夜都市：巨幅企业广告照亮酸雨，悬浮车从高楼之间穿过。镜头缓慢下降，来到陈俊生所在的企业总部。薛甄珠从雨幕中走向入口，耳后的蓝色义体接口在霓虹下短暂亮起。

### 声音节奏

- 开场先有远处雷声、酸雨敲击金属和服务器低鸣。
- 字幕出现后加入极慢的工业合成器低音，像一颗机械心脏，约 60—70 BPM。
- “有人修改权限”出现时加入一次短促的数据故障声。
- “幽灵关系持有人”出现时给一次克制的低频冲击，随后立即抽空音乐。
- 转入实景后，高跟鞋声成为第一个近距离、清晰而有攻击性的声音。

序幕建议控制在 **10—12 秒**，独立于后续的前台问询戏，避免世界观说明挤压人物对白。

## 视觉基调

整体风格是冷峻的未来黑色电影与中国家庭伦理剧的结合。

- 城市以青蓝、灰黑和少量洋红霓虹为主，雨水、玻璃、金属和企业广告构成主要环境。
- 科技必须显得日常、陈旧且具有阶级差异。富人使用无痕植入物，普通人仍依赖实体芯片和维修过的老式义体。
- 企业空间极度整洁、安静、礼貌，所有暴力都被包装成权限、流程和风险控制。
- 薛甄珠进入画面后，生活化的语言和直接的行动打破企业秩序。
- 不使用欢快复古的电子舞曲；音乐以低频工业氛围、机械脉冲和环境噪声为主。

## 人物设定

### 薛甄珠

旧城区居民，中年中国女性。年轻时做过小生意，熟悉人情世故，文化程度不高，却能凭生活经验迅速看穿谎言。她不会使用复杂的企业术语，也不接受系统替人作出的道德判断。

外观保留短卷发、鲜明的年龄感与强势神态。太阳穴至颧骨有一道很细的银色义体接缝，耳后安装旧型号蓝光接口。义体并不华丽，表面有长期使用留下的轻微磨损。

她携带一枚老式实体存储芯片，其中保存着陈俊生无法远程销毁的家庭账户记录。别人把算法、协议和权限当作遮羞布，她只追问最简单的问题：**“你明知道他有家，为什么还拿不属于你的东西？”**

人物关键词：泼辣、敏锐、护女、务实、不畏权威、生活智慧。

### 凌玲

陈俊生所在企业“员工关怀与身份合规部”的权限审核员。她没有夸张义体，外表克制、整洁、无害，说话温和且始终保持职业礼貌。

她比任何人都熟悉家庭账户的审核规则，也知道如何将私人关系伪装成临时照护、住房救助或系统误差。面对质问时，她不会立即对抗，而是不断将个人选择归因于流程、生活压力和陈俊生的主动授权。

她的危险不来自武力，而来自对制度漏洞的熟练利用。她相信只要记录足够模糊，责任就无法落到具体的人身上。

人物关键词：隐忍、精确、示弱、善用规则、自我合理化。

### 陈俊生

巨型企业中层管理者，负责城市家庭信用系统的外包项目。他拥有修改部分权限记录的内部资格，却没有承担选择后果的勇气。

他维持着体面、理性、疲惫的职场形象，将背叛解释成“关系重组”，把资源转移说成“临时授权”。他试图让系统替自己决定谁是受害者，也希望两个女人在流程中自行解决冲突。

人物关键词：体面、软弱、逃避、技术官僚、擅长模糊责任。

### 罗子君

薛甄珠的女儿，家庭联合账户的法定共同持有人。她原本依赖陈俊生提供的高等级城市权限生活，在账户资源被悄悄转移后，第一次意识到自己的身份、住所和未来都可以被别人从后台修改。

她在故事前段仍然犹豫、羞耻且不愿公开冲突。薛甄珠的闯入既替她反击，也迫使她开始建立属于自己的独立身份。

人物关键词：失序、迟疑、觉醒、重建自我。

### 企业前台机器人

银白色人形服务机器人，负责访客验证和风险拦截。声音平静、礼貌，没有恶意，只能理解系统中存在的分类。

它不认识“小三”，只认识“未登记亲密权限持有人”；不理解背叛，只能识别异常账户共享。它越认真，薛甄珠的回答就越锋利。

示例对白：

> **机器人：**“职位库中不存在‘小三’。请提供访问对象姓名。”  
> **薛甄珠：**“当然不存在。偷来的权限，谁敢写在工牌上？”

人物功能：建立世界规则、制造冷幽默，并代表企业系统对真实情感的无能。

## 创作原则

1. 保留原故事中人物关系、冲突顺序和薛甄珠压住全场的力量。
2. 赛博朋克设定必须推动剧情：出轨对应非法共享权限，婚姻对应家庭账户，财产转移对应资源授权。
3. 薛甄珠不说生硬的科技黑话。她用普通人的语言拆穿技术包装。
4. 凌玲和陈俊生越克制、越制度化，薛甄珠的直接越有力量。
5. 核心冲突始终属于人，而不是失控的人工智能或偶然的系统故障。
